# Carátulas de Folio Municipal

Aplicación local para registrar carátulas y documentos de folios municipales.

## Iniciar

```sh
npm install
npm start
```

Abre `http://localhost:3000`. Con el servidor Node, los folios se guardan en `folios.json`. Si abres los archivos con Live Server, la aplicación guarda los folios en el almacenamiento local del navegador. Las exportaciones se archivan en el historial de ese navegador y puedes volver a descargarlas aunque los folios hayan cambiado después.
